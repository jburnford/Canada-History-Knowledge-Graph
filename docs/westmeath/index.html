Westmeath at a Glance

Westmeath is a township in Renfrew County, Ontario, on the Ottawa River. Its boundaries remained stable across all eight census years (1851–1921), making it an ideal test case for the persistent place identity problem.

The source HGIS data assigns Westmeath 7 different polygon IDs across 8 census years. The v2 CIDOC-CRM model collapses these into a single persistent place.

Issue 1: ID Reuse Across Years
TCP UID ON082003 represents different physical places in different census years:
  • 1861: Burgess (Lanark County, 44.79°N 76.28°W)
  • 1871: Westmeath (Renfrew North, 45.76°N 76.88°W)
  • 1891: Plympton (Lambton West, 43.01°N 82.11°W)
  • 1901: Kemptville Village (Leeds & Grenville, 45.02°N 75.65°W)
  • 1911: Stanley (Huron S, 43.51°N 81.61°W)

The v1 model created a single E53_Place for ON082003, conflating 5 completely different townships.

Issue 2: Canonical Name Mismatch (v1)
v1 set the E53_Place name from the raw UID’s latest census year, not the place it represents:
  • ON114011 → named “Osprey” (from 1921 usage), but represents Westmeath in 1881/1891
  • ON110012 → named “Sandwich S” (from 1921 usage), but represents Westmeath in 1901
  • ON116010 → named “Hayelock” (from 1921 usage), but represents Westmeath in 1911

The Fix: Persistent Place Identity (v2)

Approach: Union-Find over SAME_AS chains (IOU = 1.0) from spatial overlap analysis. Each connected component of identical-boundary polygons across years becomes one persistent E53_Place. The original TCP UIDs are preserved as E42_Identifier provenance nodes on each E93_Presence.

Verification Query

// Find all Westmeath presences and their measurements
MATCH (place:E53_Place {place_id: 'PLACE_ON142032'})
  <-[:P166_was_a_presence_of]-(presence:E93_Presence)
  -[:P164_is_temporally_specified_by]->(period:E4_Period)
OPTIONAL MATCH (presence)<-[:P39_measured]-(m:E16_Measurement)
  -[:P40_observed_dimension]->(d:E54_Dimension)
WHERE m.label CONTAINS 'POP'
RETURN period.year AS year,
       presence.presence_id AS presence,
       presence.csd_tcpuid AS tcp_uid,
       d.value AS population
ORDER BY year

Returns 8 rows — one per census year, all from a single MATCH on the persistent place.

Provenance: E42_Identifier

Each E93_Presence retains its original TCP UID as an E42_Identifier node, so provenance back to the source HGIS data is always traceable:

// Trace TCP UIDs for Westmeath
MATCH (place:E53_Place {place_id: 'PLACE_ON142032'})
  <-[:P166_was_a_presence_of]-(p:E93_Presence)
  -[:P1_is_identified_by]->(id:E42_Identifier)
RETURN p.census_year AS year, id.value AS tcp_uid
ORDER BY year
